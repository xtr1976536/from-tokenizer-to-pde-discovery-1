# 三个问题的复核记录（暂不修改主报告）

## Reward复算

使用原Chaffee–Infante数值缓存的10,000个点复算，两个reward与保存值误差小于2e-9。评分把第一个生成项的系数固定为1，对其他项作最小二乘，reward=(1-0.2 log10 M) R²。

- 非目标新结构：sin(x) u_xx + 0.0021405684 u_tt - 0.9117297164 u_xx = 0。M=3，R²=0.9911534007，惩罚因子0.9045757491，reward=0.8965733299。
- 正确结构：u³ - 1.0085753297 u - 0.9987866884 u_t + 0.9992609062 u_xx = 0。M=4，R²=0.9992070683，惩罚因子0.8795880017，reward=0.8788905485。

正确结构拟合更好，但因4项的惩罚更强而排名落后。统一采用4项惩罚因子时，非目标式得分为0.8718066391，低于正确式。两个R²各自以首项作为拟合锚点；它们的因变量分别是-sin(x)u_xx与-u³。

## 新结构口径

在同配置、同案例下，汇总212模型三个种子、全部五轮的可识别有效候选结构，作为参照集合。636候选的有效结构ID不在此集合，即为本次新增结构。使用评分整理后的GRE，按既有规则去重复项、规范加法和乘法次序、展开命名算子；结构ID使用既有structure_id函数。原始生成结构另存为补充。这里的未见是本次记录中未见，并非模型表达能力的零概率判断。

发生次数按生成记录计算；去重按每次运行内部的结构ID计算，跨运行相加。Top10占比的分母为最终候选名额，去重新结构进入率的分母为每次运行内已评分的新结构种类数。
